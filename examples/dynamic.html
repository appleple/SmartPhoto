SmartPhoto.js - Dynamic content

SmartPhoto is constructed once with a CSS selector string (".js-smartphoto"). Click "Load more (simulate Ajax)" to append new thumbnails to the DOM after construction, without calling addItem()/addNewItem(). The newly added thumbnails still open just by clicking them. See examples/src/dynamic.js.

Click "Remove first thumbnail" to simulate an element disappearing from the DOM (e.g. after an Ajax refresh). The removal is only picked up the next time any thumbnail in the same group is opened (SmartPhoto reconciles the group against the current DOM right before opening a photo) — it is not tracked in real time while the viewer is already open.
